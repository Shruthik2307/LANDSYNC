Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Oxc](https://oxc.rs)

The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).

# LANDSYNC

LANDSYNC is an AI-enabled geospatial integration and reconciliation platform designed to harmonize multiple spatial and non-spatial land datasets.

## Problem

Urban land administration involves data from multiple sources such as cadastral maps, revenue records, municipal GIS layers, drone imagery, ORI, DSM/DTM, GNSS/CORS surveys, Ground Truthing datasets, utility networks, and building footprints.

These datasets may differ in format, coordinate systems, geometry, attributes, or recorded values. Manual GIS-based harmonization can be time-consuming and prone to errors.

## Solution

LANDSYNC automatically:

- Integrates multiple land-related datasets
- Normalizes formats and coordinate systems
- Matches corresponding parcels/features
- Detects geometry, area, attribute and spatial conflicts
- Performs spatial analytics
- Generates confidence scores
- Prioritizes records for authorized verification
